# OpenCode v1.16.2：后台子代理与安全编辑

**发布日期**：2026 年 6 月 5 日

## 一句话总结

本版本让运行中的子代理可转入后台，同时收紧编辑匹配并修复多种模型、权限、终端和桌面问题。

## 新功能或行为变化

- 运行中的子代理可转入后台，让用户继续处理当前会话；该能力仍受实验性后台模式控制。
- 新增 Snowflake Cortex Provider 支持。
- TUI diff viewer 支持上一个/下一个 hunk 导航。
- 长会话会持久化系统上下文更新。
- 编辑操作会拒绝可能覆盖错误代码或误替换已有文件的宽松匹配。
- 桌面端增强多服务器支持，为各服务器分别保存 Home 状态和会话标签。

## 问题修复

- 仅在 Provider 支持时生成推理摘要，避免兼容后端上的 GPT-5 请求失败。
- 修复 Bedrock 在模型响应开始前卡住的问题。
- 修复 attach 模式下原项目路径不可用时，外部编辑器无法回退打开的问题。
- 修复权限回复路由到错误会话目录，以及畸形路径或 diff 元数据导致界面崩溃。
- 修复终端主题热重载后的旧颜色、标题栏标签溢出、滚动与关闭后选中标签不稳定。

## 影响范围

- **Core / TUI**：使用子代理、编辑工具、权限和 diff viewer 的用户。
- **Provider**：GPT-5 兼容后端、Bedrock 与 Snowflake Cortex 用户。
- **Desktop**：多服务器和大量标签页用户。

## 是否需要升级

使用后台子代理、Bedrock、Snowflake Cortex 或遇到编辑误匹配与桌面标签问题的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
