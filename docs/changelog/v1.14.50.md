# v1.14.50：持续事件流与模型错误改进

**发布日期**：2026 年 5 月 14 日

## 一句话总结

HTTP 事件流会持续接收实例更新，并改善会话 busy、模型缺失和 Markdown 输出处理。

## 新功能或行为变化

- HTTP 事件流在初始 connect 事件后保持打开，订阅者可继续收到实例更新。
- V2 模型和 Provider 调用支持 `instance.directory` 与 `instance.workspace` 查询参数。
- 会话输出默认恢复 Markdown 渲染。

## 问题修复

- 会话正在执行提示或 shell 工作时返回正确的 busy 错误。
- 无效 `small_model` 配置会安全回退，不再破坏小模型选择。
- CLI 和类型化调用方的模型缺失错误会提供更明确的建议。

## 影响范围

影响 Server 事件订阅、V2 API、CLI、模型配置和会话执行用户。

## 是否需要升级

依赖事件流、workspace-aware V2 API 或遇到模型选择问题时建议升级。

## 升级命令

```bash
opencode upgrade
```
