# v1.14.49：V2 模型 API 与配置体验升级

**发布日期**：2026 年 5 月 13 日

## 一句话总结

新增 V2 模型与 Provider API、DigitalOcean OAuth 和默认全局配置，同时大幅改善 TUI 会话与提示词体验。

## 新功能或行为变化

- 新增 V2 模型与 Provider 列表 API，并加入 DigitalOcean OAuth 和 Inference Router。
- 没有配置时自动创建全局 `opencode.jsonc`，默认启用带完整 schema 链接的 `customize-opencode`。
- 提示词支持已配置 `@mentions` 自动补全，patch diff 默认解析 Markdown 围栏代码块。
- 新增固定最近会话、快捷槽位、最近会话循环和项目快速切换快捷键。
- 压缩后保留近期轮次，切换会话或项目时记住模型 variant。

## 问题修复

- 修复 keymap 回退优先级、配置错误提示、未加载 Provider 模型建议和分层权限规则顺序。
- 修复自定义工具附件丢失、宽字符光标与 mention、重复提交产生空会话、fork 后历史丢失。
- 修复非交互 `run` 退出、`run --json` 输出排空、提示历史、流式 Markdown 截断和 workspace 切换闪烁。
- 修复 Desktop Linux 元数据、环境变量加载、Server 错误展示和关闭项目后的导航。

## 影响范围

影响 Core、TUI、CLI、Server、SDK、Provider 认证、配置文件与 Desktop 用户。

## 是否需要升级

使用 V2 API、DigitalOcean、全局配置或会话快捷切换时建议升级；新配置文件应优先使用 `opencode.jsonc`。

## 升级命令

```bash
opencode upgrade
```
