# OpenCode v1.17.2：认证恢复与子代理权限

**发布日期**：2026 年 6 月 10 日

## 一句话总结

远程配置认证过期后可重新登录恢复，子代理也重新使用自身配置的权限，同时保留父会话的关键限制。

## 新功能或行为变化

- 远程配置认证过期时会提示重新登录，而不是直接导致配置加载失败。
- 子代理重新使用自身配置的权限，同时继承父会话的 `deny` 与 `external_directory` 规则。

## 问题修复

- 恢复 Linux 启动器和图标身份，固定到桌面的应用可正确打开。
- 恢复设备附件选择器。

## 影响范围

- **Core**：使用远程配置、子代理和细粒度权限策略的用户。
- **Desktop**：Linux 桌面用户与需要选择设备附件的用户。

## 是否需要升级

使用远程配置或子代理权限的用户建议升级；Linux Desktop 用户也应升级以恢复启动器行为。

## 升级命令

```bash
opencode upgrade
```
