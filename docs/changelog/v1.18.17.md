# OpenCode v1.18.17 更新日志

**发布日期**：2026-08-12

## 一句话总结

本版本让会话压缩保留完整近期轮次，并限制自动重试以减少重试风暴。

## 新功能或行为变化

- 会话压缩保留完整近期轮次，并为小模型生成更清晰的摘要。
- MERGE Gateway 增加推理变体；支持 PDF 视觉的 GitHub Copilot 模型可接收 PDF 附件。
- DeepSeek V4 Flash 使用正确采样默认值，Muse 系列使用正确 Meta 系统提示。

## 问题修复

- 自动会话重试增加上限和随机抖动，降低重复重试风暴。
- 默认模型改用服务器当前值，不再使用过期的本地配置。
- 更新中文开发术语为更通用的译法。

## 影响范围

影响长会话与小模型用户，以及 MERGE Gateway、GitHub Copilot、DeepSeek、Meta Muse 和多服务器用户。

## 是否需要升级

长会话、频繁重试或使用上述模型的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
