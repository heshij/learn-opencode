# OpenCode v1.17.9：Agent 步数上限收尾

**发布日期**：2026 年 6 月 21 日

## 一句话总结

Agent 达到配置的步骤上限时会强制给出最终文本回复，而不是在运行中途失败。

## 新功能或行为变化

- Agent 达到步骤上限时会转为最终文本回复，确保运行有明确结果。
- 为受支持 Provider 上的 GLM-5.2 新增 `high` 和 `max` thinking variants。
- 仅当服务器支持时显示后台子代理快捷键。

## 问题修复

- 修复 Provider ID 大小写不同时 Devstral 模型识别失败。
- GitHub Copilot 模型请求会传递已配置的自定义 header。
- 后续用户消息不再包裹 steering reminder，以保持提示词缓存有效。

## 影响范围

- **Core / Agent**：配置执行步数上限和长任务的用户。
- **Provider**：Devstral、GLM-5.2 与 GitHub Copilot 用户。
- **TUI / Server**：使用后台子代理快捷键的用户。

## 是否需要升级

配置 Agent 步数上限，或使用 Devstral、GLM-5.2、Copilot 自定义 Header 的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
