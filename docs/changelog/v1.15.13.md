# v1.15.13：Reasoning、会话元数据与配置加载

**发布日期**：2026 年 5 月 30 日

## 一句话总结

修复 Gateway 上 Anthropic adaptive reasoning 摘要，并为会话 API/SDK 增加自定义元数据，调整目录配置加载顺序。

## 新功能或行为变化

- 会话可通过 API 和 SDK 存储自定义 metadata。
- 配置从打开位置向上查找加载，使目录专属设置和 Provider 策略更可预测。
- 换行后的行内工具行保持对齐，失败工具可就地展开错误详情。

## 问题修复

- 修复 Gateway 中 Anthropic Opus 4.7+ adaptive reasoning 返回空 thinking block 的问题，现在会保留总结后的 thinking。

## 影响范围

影响 Anthropic Gateway、Core 配置、目录级 Provider 策略、API、SDK、TUI 以及 ACP 相关用户。

## 是否需要升级

使用 Opus 4.7+ adaptive reasoning、会话 metadata 或目录级配置时建议升级。

## 升级命令

```bash
opencode upgrade
```
