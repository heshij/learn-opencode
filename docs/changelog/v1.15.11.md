# v1.15.11：Provider 超时与后台 Agent 推送

**发布日期**：2026 年 5 月 27 日

## 一句话总结

Provider 请求可配置 header timeout，实验性后台 Agent 改为主动推送更新，并改善 MCP、reasoning、TUI 与 Desktop。

## 新功能或行为变化

- Provider 请求新增 `headerTimeout` 配置；默认 OpenAI 设置的默认值为 10 秒。
- 实验性后台 Agent 无需轮询即可推送更新。
- 配置可仅设置 `modalities.input` 或 `modalities.output`，实验开关也可覆盖总开关。
- shell 工具会向模型说明已配置的 timeout，插件新增 `dispose` hook。
- TUI prompt 可随终端宽度调整，并支持 prompt 大小配置。

## 问题修复

- 远程项目获得稳定身份，动态移除 MCP Server 时会正确断开连接。
- 修复用户信息不可用时配置加载、Google tool calling、恢复会话继续孤立工具和 Codex session ID header。
- DigitalOcean inference 直接使用 OAuth token；OpenAI reasoning summary 分块显示，Vertex 支持 reasoning signatures。
- 修复 Desktop v2 缓存删除后的标题栏错误、Web 误跑 Desktop health check、重复 Server 连接和窗口恢复白闪。

## 影响范围

影响 Provider、实验性后台 Agent、MCP、TUI、插件、Desktop、Web 和远程项目用户。

## 是否需要升级

需要 Provider 超时控制、后台 Agent 推送或插件清理钩子时建议升级；实验性后台能力仍需谨慎使用。

## 升级命令

```bash
opencode upgrade
```
