# OpenCode v1.18.2 更新日志

**发布日期**：2026-07-15

## 一句话总结

本版本默认阻止子代理继续嵌套启动子代理，并允许通过 `subagent_depth` 显式调整深度。

## 新功能或行为变化

- 子代理默认嵌套深度为 1；需要更深嵌套时可配置 `subagent_depth`。
- 后台子代理仍受实验开关控制，运行中的子代理可在 TUI 中转入后台。
- 改进 Meta 模型默认推理深度，并增加 `Mod+N` 新标签页快捷键。

## 问题修复

- 恢复发行版中的 Help 按钮。
- 修复归档时间为 `null` 的会话从首页消失，以及 Windows 抽屉关闭按钮与窗口控件冲突的问题。

## 影响范围

主要影响 Agent/子代理、TUI、Server、SDK 和 Desktop 用户。依赖嵌套子代理的配置可能需要显式设置深度。

## 是否需要升级

使用子代理的用户应升级并检查 `subagent_depth`；遇到会话列表或 Windows 界面问题的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
