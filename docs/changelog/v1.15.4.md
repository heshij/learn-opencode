# v1.15.4：项目事件与 LSP 刷新修复

**发布日期**：2026 年 5 月 17 日

## 一句话总结

修复项目作用域事件和自定义 LSP 刷新，并仅在实验模式启用时显示后台子代理指令。

## 新功能或行为变化

- Markdown H1 标题的视觉区分更加明显。
- 只有启用实验性后台模式时，才显示后台子代理任务指令。

## 问题修复

- 修复项目作用域 bus 事件未把文件监视和更新通知发送到正确实例的问题。
- 修复自定义 LSP Server 初始化后不发送刷新事件的问题。

## 影响范围

影响项目事件、文件监视、自定义 LSP、TUI Markdown 显示和实验性后台子代理用户。

## 是否需要升级

使用自定义 LSP 或依赖文件更新通知时建议升级。

## 升级命令

```bash
opencode upgrade
```
