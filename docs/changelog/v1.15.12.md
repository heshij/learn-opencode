# v1.15.12：ACP Next 与 OpenAI WebSocket

**发布日期**：2026 年 5 月 28 日

## 一句话总结

ACP 集成获得提示、slash command 和用量更新能力，并实验性支持 OpenAI WebSocket 响应传输。

## 新功能或行为变化

- `acp-next` 可发送提示、slash command 和 usage 更新，并提升热切换与首会话启动速度。
- 设置 `OPENCODE_EXPERIMENTAL_WEBSOCKETS=true` 后，支持的 OpenAI 渠道可使用 WebSocket transport，也支持自定义 base URL。
- Anthropic Opus 4.7+ 支持 adaptive reasoning 控制。
- 新增 workspace 管理对话框和 tab 布局切换设置。
- 密码现在允许包含冒号。

## 问题修复

- 保持 OpenAI WebSocket timeout，失败流会先重试再回退。
- 修复 `acp-next` 权限提示、已有会话目录、远程 workspace request body 转发。
- 修复提示模式打开时会话导航、thinking spinner、子代理重试状态和非 Git 路径打开编辑器。
- 改善首页空状态和 V2 字体，并修复 tab 关闭按钮显示不稳定。

## 影响范围

影响 ACP/IDE 集成、OpenAI、Anthropic、Core、SDK、workspace、Desktop 和 Web 用户。

## 是否需要升级

使用 ACP、Opus 4.7+ 或想试用 OpenAI WebSocket 时建议升级；WebSocket transport 仍需实验开关。

## 升级命令

```bash
opencode upgrade
```
