# OpenCode v1.17.5：Snowflake OAuth 与 MCP 恢复

**发布日期**：2026 年 6 月 13 日

## 一句话总结

Snowflake Cortex 新增外部浏览器 OAuth，MCP 过期会话可自动恢复，同时改善工具输出、会话迁移和界面稳定性。

## 新功能或行为变化

- Snowflake Cortex Provider 支持外部浏览器 OAuth。
- 改进 v2 项目副本管理与移动会话流程。
- MCP 结构化工具输出以可读形式返回。
- Web 应用支持 v2 visibility 设置。
- 更新 `oc-2` 主题，并改善终端尺寸调整区域和标题栏标签溢出效果。

## 问题修复

- MCP 会话过期后会恢复连接，并清理已关闭客户端，避免残留失效连接。
- 修复重复 renderable ID 导致的 TUI 渲染问题。
- 修复命令使用 `$ARGUMENTS` 时重复注入文件内容。
- `RunCommand` fetch 请求现在携带认证 header。

## 影响范围

- **Provider / Integrations**：Snowflake Cortex OAuth 用户。
- **MCP / Core**：长时间运行、会话过期或依赖结构化工具输出的 MCP 用户。
- **TUI / Web / Desktop**：命令模板、v2 visibility 与标签界面用户。

## 是否需要升级

使用 Snowflake Cortex、MCP 或 `$ARGUMENTS` 命令模板的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
