# v1.15.2：减少提示并修复项目作用域

**发布日期**：2026 年 5 月 16 日

## 一句话总结

减少 shell、task 和 todo 流程中的不必要提示，并修复项目作用域事件与本地 Agent 解析。

## 新功能或行为变化

- shell、task 和 todo 流程减少不必要的提示。
- 新固定的会话保留在固定列表末尾，不再跳到顶部。

## 问题修复

- 修复注入实例中的 sync 事件无法到达项目作用域订阅者的问题。
- 修复 `opencode run --agent` 无法解析项目本地 Agent 的问题。

## 影响范围

影响 CLI、Agent、项目事件订阅、TUI 固定会话以及 shell/task/todo 工作流。

## 是否需要升级

使用项目本地 Agent 或依赖项目事件时建议升级；其他用户可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
