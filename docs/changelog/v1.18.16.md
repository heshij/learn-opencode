# OpenCode v1.18.16 更新日志

**发布日期**：2026-08-10

## 一句话总结

本版本让配置解析容忍未知顶层字段，并改善 Desktop 的项目发现、右键菜单和 macOS 窗口行为。

## 新功能或行为变化

- 配置解析会忽略未知顶层字段，不再因此失败。
- v2 只发现 `opencode.json` 和 `opencode.jsonc`；v1 loader 仍读取旧全局 `config.json`，新建全局配置默认使用 `opencode.jsonc`。
- 首页打开的项目会注册到应用其他区域，并可右键打开项目菜单。
- 项目选择器服务器不支持搜索时，会回退到本地目录列举和匹配。
- macOS 关闭最后一个窗口后应用保持运行，再次激活时会重新打开窗口。

## 问题修复

- 简体中文中 token 相关标签改用“词元”，并更新项目中对应术语。

## 影响范围

影响配置文件、Desktop 项目管理、简体中文界面和 macOS 用户。使用旧全局 `config.json` 的用户需留意 v1/v2 配置发现差异。

## 是否需要升级

遇到未知配置字段报错或使用上述 Desktop 场景的用户建议升级；配置迁移前应确认当前使用的是 v1 还是 v2。

## 升级命令

```bash
opencode upgrade
```
