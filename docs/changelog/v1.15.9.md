# v1.15.9：新版 Diff Viewer 默认启用

**发布日期**：2026 年 5 月 22 日

## 一句话总结

重新设计并默认启用带文件树的 diff viewer，同时让模型、PTY、MCP 和会话 API 错误更明确。

## 新功能或行为变化

- diff viewer 使用新的文件树与布局，并默认启用；关闭后返回上一屏，还可复制当前 worktree 路径。
- MCP OAuth 配置支持 callback port，并把配置的 scopes 写入客户端元数据。
- Desktop 标题栏显示会话状态，并承载 tab 导航。

## 问题修复

- 改善 diff viewer 空状态、上下文和键盘快捷键，并恢复问题提示按键处理。
- 默认模型无效、Skill 调用预期失败、安装升级失败时会显示更明确的错误。
- HTTP API 返回 PTY、项目不存在、MCP Server 不存在和会话 busy 的具体错误正文。
- 修复 Vertex Anthropic `us`/`eu` 多区域端点、原生 reasoning 延续元数据和 callback user code 提取。
- 对 VCS 刷新进行防抖，减少会话页面抖动。

## 影响范围

影响 TUI、模型配置、Server、MCP OAuth、Vertex Anthropic 和 Desktop 用户。

## 是否需要升级

使用 diff viewer、MCP OAuth 或依赖类型化 API 错误时建议升级。

## 升级命令

```bash
opencode upgrade
```
