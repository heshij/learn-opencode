# v1.14.42：Scout、workspace 同步与 API 增强

**发布日期**：2026 年 5 月 9 日

## 一句话总结

本版本加入 Scout、workspace 自动同步和 `opencode run` 交互模式，并系统性改善 HTTP API 与模型推理选项。

## 新功能或行为变化

- 新增 Scout Agent，用于仓库研究、文档查找和依赖源码检查。
- 新增适配器支持的 workspace 自动发现与注册。
- `opencode run` 新增交互式 split-footer 模式。
- TUI 快捷键配置改为扁平 `keybinds` 映射。
- 大型非流式 HTTP API 响应支持压缩，API 也会返回结构化校验错误和带认证 challenge 的类型化 `401`。
- Skills 即使没有 description 也可以加载，工具列表顺序保持稳定。

## 问题修复

- 修复 HTTP API 授权兼容格式、OpenAPI 文档路由、无效权限或问题 ID，以及 effect 根路由鉴权。
- 修复 detached session 归属、npm shim 信号转发和重复 worktree 名称显示。
- 修正 Gemini、Anthropic、OpenAI 与 GPT-5 系列的 reasoning effort 选项。
- 修复 TUI 重试提示、项目侧栏状态、会话排序、草稿历史和 Desktop 静默更新流程。

## 影响范围

影响 Core、TUI、CLI、Desktop、Web、Server、SDK 与 workspace 用户。

## 是否需要升级

使用 HTTP API、TUI 自定义快捷键、workspace 或推理模型时建议升级；需注意快捷键配置格式变化。

## 升级命令

```bash
opencode upgrade
```
