# OpenCode v1.18.6 更新日志

**发布日期**：2026-07-27

## 一句话总结

本版本修复不同分支仓库缓存互相干扰的问题，并改善 Desktop 新旧服务器兼容性。

## 新功能或行为变化

- 改善新版客户端 API 在目录、项目、会话和终端流程中的兼容性。

## 问题修复

- 修复按分支缓存的仓库刷新一个引用时意外移动另一个分支检出的问题。
- 修复打开 v1 工作区时旧版 MCP 状态不刷新。
- 修复 v1 服务器连接 Provider 或完成 OAuth 后模型列表不刷新。

## 影响范围

主要影响多分支仓库、v1 工作区、MCP、Provider OAuth 和 Desktop 用户。

## 是否需要升级

使用上述场景的用户建议升级，尤其是并行使用多个分支缓存的用户。

## 升级命令

```bash
opencode upgrade
```
