# v1.15.3：大文件读取与异步上下文修复

**发布日期**：2026 年 5 月 16 日

## 一句话总结

减少大文件输出被截断后的无效读取，并修复异步命令丢失当前实例上下文的问题。

## 新功能或行为变化

- 大文件读取在输出截断后会减少重复和无效工作。

## 问题修复

- 修复异步命令丢失当前实例上下文，导致 Agent 生成或 GitHub 驱动运行失败的问题。

## 影响范围

影响读取大型文件、异步命令、Agent 生成和 GitHub 集成用户。

## 是否需要升级

使用大型仓库、异步命令或 GitHub 驱动流程时建议升级。

## 升级命令

```bash
opencode upgrade
```
