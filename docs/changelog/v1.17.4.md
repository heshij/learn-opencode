# OpenCode v1.17.4：MCP 工作目录与 V2 API

**发布日期**：2026 年 6 月 12 日

## 一句话总结

本版本允许本地 MCP 服务器从工作区相对目录启动，并扩展认证、V2 会话 API 与 SDK 文件读取能力。

## 新功能或行为变化

- 本地 MCP 服务器新增 `cwd`，可指定工作区相对启动目录。
- 新增 connector 驱动的认证流程与已保存 Provider 凭据支持。
- V2 API 新增创建/读取会话、列出会话问题和解析当前位置的端点。
- API 与 SDK 的文件读取返回带正确 Content-Type 的原始内容。
- MCP 服务器日志通知会写入 OpenCode 日志。
- 创建 snapshot 时复用源 Git 对象，减少大型仓库重复哈希耗时。

## 问题修复

- 修复 Gemini 多类型字段工具 schema 的兼容性。
- 内容过滤后的模型响应会显示明确错误，不再静默失败。
- 修复 MCP 认证与 debug 请求丢失自定义 header。
- 修复列出 MCP prompts、resources 或 tools 时未应用目录请求超时。

## 影响范围

- **MCP / Core**：本地 MCP 启动目录、日志、认证和大型工具目录用户。
- **Server / SDK**：使用 V2 会话、问题、位置与文件读取 API 的开发者。
- **Provider / Integrations**：Connector 凭据与 Gemini 工具调用用户。

## 是否需要升级

使用本地 MCP、V2 API、Connector 认证或大型 Git 仓库的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
