# OpenCode v1.18.12 更新日志

**发布日期**：2026-08-04

## 一句话总结

本版本修复 Azure GPT-5.5+ 开启推理时的请求失败，并减少大图片或附件草稿造成的输入卡顿。

## 新功能或行为变化

- 项目搜索可匹配所有已知最近项目，不再只搜索前五项。

## 问题修复

- 修复 Azure GPT-5.5+ completion 请求启用推理时失败。
- 降低包含大图片或附件的 Composer 草稿延迟。
- 同一轮恢复流式输出后，清除时间线中的旧助手错误。
- 连接 v2 服务器时跳过旧版配置读取，避免无关的配置加载问题。

## 影响范围

影响 Azure GPT-5.5+、Desktop Composer、项目搜索、时间线和 v2 服务器用户。

## 是否需要升级

使用 Azure GPT-5.5+ 推理或大附件草稿的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
