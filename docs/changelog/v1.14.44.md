# v1.14.44：修复 workspace 升级失败

**发布日期**：2026 年 5 月 9 日

## 一句话总结

修复已有 workspace 在新增 `time_used` 字段时无法升级的问题。

## 新功能或行为变化

本版本 Release Notes 未单独列出新功能或行为变化。

## 问题修复

- 修复已有 workspace 因新增 `time_used` 字段而升级失败的问题。

## 影响范围

主要影响从旧版本升级且已有 workspace 数据的用户。

## 是否需要升级

遇到 workspace 数据升级失败时应升级；新安装或未受影响用户可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
