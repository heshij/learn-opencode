# OpenCode v1.18.11 更新日志

**发布日期**：2026-08-01

## 一句话总结

本版本修复 MCP SSE 错误响应后的无限重连，并改善自定义推理字段和 Desktop 交互。

## 新功能或行为变化

- 外部链接改为使用系统浏览器打开，而不是在应用内打开。

## 问题修复

- 修复 MCP HTTP/SSE 错误响应导致连接反复重连的问题。
- 修复使用 `reasoning_text` 或自定义交错推理字段的 Provider 模型配置。
- 修复 Desktop 标题栏会话标签状态过期、旧版目录选择器无首页路径时的起始目录、文件树标签缩小时裁切，以及调试栏标签和值错位。

## 影响范围

主要影响 MCP、使用自定义推理字段的 Provider，以及 Desktop 用户。

## 是否需要升级

遇到 MCP 重连循环的用户应尽快升级；其他受影响用户建议升级。

## 升级命令

```bash
opencode upgrade
```
