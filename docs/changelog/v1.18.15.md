# OpenCode v1.18.15 更新日志

**发布日期**：2026-08-07

## 一句话总结

本版本统一按真实时间处理消息顺序，避免旧 ID 影响时间线、回退、分叉和会话列表。

## 新功能或行为变化

- 可从界面将完整会话记录导出为 JSON。
- Desktop 增加更广泛的语言覆盖，语言选择器保留语言原生名称，并补齐现有翻译。
- TUI 快捷键配置已包含 diff、后台会话、Skill 与 cursor 等键位，绑定可用 `none` 或 `false` 禁用。

## 问题修复

- 导入或旧消息 ID 无序时，消息仍按创建时间排列；回退和分叉也按真实时间顺序执行。
- 会话时间线边界、持久化消息顺序和会话列表活动时间排序更加可靠。
- 重复压缩会保留更早的工具调用历史，截断清理按文件时间更可靠。
- 修复 Web UI 加载 Blob 附件。

## 影响范围

影响导入或迁移的旧会话、回退/分叉、会话压缩、Web 附件、TUI 快捷键和 Desktop 多语言用户。

## 是否需要升级

使用旧会话、回退/分叉或会话导出的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
