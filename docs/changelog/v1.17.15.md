# OpenCode v1.17.15 更新日志

**发布日期**：2026-07-07

## 一句话总结

本版本让 Z.ai 上下文溢出错误更准确，并修整 Desktop v2 的命令面板、终端快捷键和标签页反馈。

## 新功能或行为变化

- 终端获得焦点时，终端快捷键优先于应用快捷键。
- 有待回答问题的标签页会显示未读状态，主题只在用户于设置中选定后应用。

## 问题修复

- 更准确地区分 Z.ai 上下文窗口溢出错误。
- 配置目录不可用时，读取配置会更稳健。
- 恢复模型选择器详情提示，并修复重载期间标签页标题丢失。
- 修复 macOS Sequoia 标题栏外观和窗口控制按钮位置。

## 影响范围

主要影响 Z.ai 用户，以及使用 Desktop v2、集成终端和 macOS 的用户。

## 是否需要升级

遇到上述错误或界面问题的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
