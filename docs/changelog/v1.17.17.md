# OpenCode v1.17.17 更新日志

**发布日期**：2026-07-09

## 一句话总结

本版本改善 Meta 模型的推理变体和请求处理，并继续打磨 Desktop v2 会话界面。

## 新功能或行为变化

- 改进 Meta 模型的推理变体与 Provider 请求处理。
- 新增可关闭的标签页介绍提示和 v2 免费模型选择器。
- 子代理任务行与回退操作栏更新为更清晰的 v2 设计。

## 问题修复

- 修复模型选择器标签文字下缘被裁切的问题。

## 影响范围

主要影响 Meta 模型用户和使用 Desktop v2 模型选择、子代理及会话回退功能的用户。

## 是否需要升级

使用 Meta 模型或遇到模型选择器显示问题的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
