# OpenCode v1.17.7：插件连接与 MCP Workspace Root

**发布日期**：2026 年 6 月 14 日

## 一句话总结

插件请求不再假定默认本地端口，MCP 可接收当前工作区 root，PTY 与 ACP 的运行上下文也更完整。

## 新功能或行为变化

- 插件客户端请求复用当前活动服务器，而不是固定连接默认本地端口。
- MCP 服务器可接收当前工作区作为 client root，MCP debug 使用 SDK 的最新协议版本。
- 插件提供的 Shell 环境变量会应用到 PTY 会话。
- ACP Shell 工具从开始执行时就显示命令和工作目录。
- SDK 会在集成变化时刷新模型与 Provider 可用性；凭据更新和删除调用支持 `location`。

## 问题修复

- 修复新会话路由未绑定自身草稿服务器，导致提示词和状态可能发往错误工作区的问题。

## 影响范围

- **SDK / Plugin**：连接非默认服务器、注入 Shell 环境变量或管理凭据的插件开发者。
- **MCP / Core**：依赖 workspace root 或调试协议版本的 MCP 服务。
- **IDE / ACP**：查看 Shell 调用上下文的 ACP 客户端。
- **Desktop / Web**：使用多服务器新会话草稿的用户。

## 是否需要升级

使用远程服务器、插件、MCP workspace root 或多服务器新会话的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
