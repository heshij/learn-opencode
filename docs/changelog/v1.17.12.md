# OpenCode v1.17.12：Claude 自适应思考与权限自动批准

**发布日期**：2026 年 6 月 30 日

## 一句话总结

本版本启用 Claude Sonnet 5 自适应思考，并集中增强 MCP OAuth、权限自动批准、提示词补全和 V2 会话运行时能力。

## 新功能或行为变化

- Claude Sonnet 5 启用 adaptive thinking，并改进跨 Provider 的默认小模型选择。
- 新增自动批准权限模式。Release Notes 称为 yolo mode，公开 CLI 参数实际为 `--auto`；`--yolo` 仅是隐藏兼容别名，显式 `deny` 规则仍生效。
- Composer 支持 MCP resources 与已配置 references 自动补全，新会话增加 workspace 控件。
- 会话上下文显示已存储 token 和成本总计，并恢复 auto-accept 设置。
- 新增实时事件订阅、活动会话查询、分页持久会话历史，以及创建和读取会话权限请求的 API。
- V2 会话恢复事件流、中断和消息查询等运行时操作，并支持新提示词唤醒嵌入式会话执行。
- V2 配置仅发现 `opencode.json` 和 `opencode.jsonc`；旧全局 `config.json` 仍由 v1 loader 读取。

## 问题修复

- MCP 同时返回 content 和 structured output 时优先使用 content；OAuth 后即使服务器已禁用也会重连。
- MCP OAuth 请求 refresh-token scope，错误信息更明确，认证状态按服务器 URL 隔离。
- 刷新远程 Skill 缓存并保留 Skill resource 路径。
- 修复 Composer 重新聚焦后的光标、提升会话后的模型选择、并发事件下页面同步和隐藏终端标签卡住。
- 修复 ServerAuth Header 转发、Desktop Provider 普通认证输入、多服务器标签与 Home 选择状态。
- 修复 V2 工具结果、重复模型切换事件、SSE 事件名和 URI 附件 MIME 类型。

## 影响范围

- **Core / Provider**：Claude Sonnet 5、默认小模型、Skill、references 与配置文件用户。
- **TUI / CLI**：使用权限自动批准时应采用公开参数 `--auto`，并保留必要的 `deny` 规则。
- **MCP / Integrations**：OAuth、resources、远程 Skill 和多服务器用户。
- **Server / SDK**：使用 V2 事件流、活动会话、历史分页、权限请求和运行时操作的开发者。
- **Desktop / Web**：多服务器标签、Home 项目和会话同步用户。

## 是否需要升级

使用 Claude Sonnet 5、MCP OAuth/resources、`--auto` 或 V2 会话 API 的用户建议升级；自动批准权限会扩大无需确认的操作范围，应仅在可信环境使用。

## 升级命令

```bash
opencode upgrade
```
