# OpenCode v1.18.8 更新日志

**发布日期**：2026-07-28

## 一句话总结

本版本加强新版 MCP 服务器与 OAuth 流程兼容性，并改善 Desktop 的项目和标签页交互。

## 新功能或行为变化

- 新会话增加打开项目选择器的快捷方式，标签页键盘导航按可见顺序移动。
- 集成需要处理时，服务器状态显示为蓝色；Provider 连接状态会在修改后立即刷新。
- Linux 包安装 AppStream 元数据，本地 Desktop 运行使用 channel 数据库。
- MCP 已支持 workspace-relative `cwd`、roots/capabilities、服务器 instructions、resources/templates 与应用内补全；历史上的临时工具命名已恢复旧命名。

## 问题修复

- MCP SDK 会话过期后可重连，包含并发请求；`mcp debug` 遵守 OAuth 回调端口。
- 停止向新版 Gemini 模型发送已弃用的采样默认值。
- 修复 Windows 文件夹路径展开，以及从 Home 关闭项目或加载右侧面板时界面冻结。

## 影响范围

影响 MCP/OAuth、Gemini、Desktop、Windows 和 Linux 打包用户。

## 是否需要升级

使用 MCP、OAuth 或遇到 Desktop 冻结的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
