# OpenCode v1.17.19 更新日志

**发布日期**：2026-07-13

## 一句话总结

本版本加入 OpenAI Pro 推理与 Luna OAuth，并大幅改进 Desktop v2 的模型选择、附件和审查面板。

## 新功能或行为变化

- 支持 OpenAI Pro 推理模式和 Luna Responses Lite OAuth；GPT-5.6 OAuth 使用 Codex 上下文限制。
- xAI Responses 默认不存储响应，CLI 环境变量会传递给 TUI worker。
- Composer 支持为每次提示单独选择模型；会话支持中键在新标签页打开，并提供临时的新旧界面切换设置。
- 更新附件卡片、文件评论、项目编辑窗口和审查面板的文件浏览体验。

## 问题修复

- 修复标签和分支提示裁切、审查面板宽度跳动、时间线上下文统计与轮廓显示等问题。
- 减少新会话更新阻塞，打开新会话时会自动聚焦提示输入框。

## 影响范围

影响 OpenAI、xAI、Luna 用户，以及 Desktop v2、TUI 和代码审查工作流用户。

## 是否需要升级

需要新推理/OAuth 能力或使用 Desktop v2 的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
