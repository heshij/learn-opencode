# v1.15.10：恢复 Desktop 生产流程

**发布日期**：2026 年 5 月 23 日

## 一句话总结

生产版 Desktop 恢复旧的项目打开和会话启动流程。

## 新功能或行为变化

- 生产版 Desktop 的项目打开和会话启动行为恢复为旧流程。

## 问题修复

本版本 Release Notes 未单独列出问题修复。

## 影响范围

仅主要影响 Desktop 用户，特别是使用项目打开和新建会话流程的用户。

## 是否需要升级

Desktop 新流程影响正常打开项目或启动会话时建议升级；其他产品线用户无需专门为此版本升级。

## 升级命令

```bash
opencode upgrade
```
