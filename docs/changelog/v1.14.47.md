# v1.14.47：恢复 TUI 编辑键与上下文稳定性

**发布日期**：2026 年 5 月 11 日

## 一句话总结

恢复 TUI 提示词编辑按键，并改善模型持久化、Scout references、图片附件和路径显示。

## 新功能或行为变化

- Scout 可以预先物化已配置的 reference 仓库，便于立即搜索。
- 大图片附件发送前会按可配置限制自动缩放。
- 文件和目录路径会尽量相对会话目录显示。

## 问题修复

- 恢复 TUI textarea 中的提示词编辑快捷键，包括 `esc`、`enter` 等别名。
- 修复模型切换无法可靠保存的问题。
- HTTP API schema 校验错误现在返回可读的 `400` 响应正文。

## 影响范围

影响 TUI、模型切换、Scout、图片附件和 HTTP API 用户。

## 是否需要升级

依赖 TUI 编辑键、模型持久化或大图附件时建议升级。

## 升级命令

```bash
opencode upgrade
```
