# OpenCode v1.17.0：大型项目搜索提速

**发布日期**：2026 年 6 月 10 日

## 一句话总结

本版本用 `fff` 大幅加速大型项目文件搜索，并全面增强 MCP、模型兼容、工作区迁移和 Windows WSL 桌面体验。

## 新功能或行为变化

- 文件搜索工具改用 `fff`，大型项目中的搜索速度更快。
- 代理场景新增 `X-Session-Id` 响应头，便于进行粘性路由。
- 新增 Cohere North、Claude Fable 推理和 MiniMax M3 thinking toggle；vLLM 可使用交错 `reasoning` 字段。
- `mcp add` 支持非交互流程，MCP 目录支持分页，并按服务器声明的 capabilities 工作。
- 工作区会话移动流程支持更清晰的项目副本标识、删除副本、切换前初始化和新目录提醒。
- Desktop 新增 Windows WSL 后端与 WSL 服务器管理；提示词草稿在标签切换时保留。
- v2 大型工具输出设有上限，并返回保留输出的路径供后续检查。

## 问题修复

- 修复 MCP 调用取消、超大目录截断、状态刷新和连接状态信息不清晰的问题。
- 修复 OpenRouter 推理 variant、Bedrock Mantle API Key/区域配置和上下文溢出后的恢复。
- 修复 Java 多模块 Maven 项目未从最上层 `pom.xml` 解析 JDTLS。
- 修复隐藏 Agent 被循环选中、附件从错误项目打开，以及多项 WSL 和 Electron 布局问题。
- 改进应用更新，使其保持响应并可跨重启继续。

## 影响范围

- **Core / TUI**：大型代码库、工作区与多会话用户。
- **MCP / Server**：依赖大型 MCP 目录、取消或代理粘性路由的集成。
- **Provider**：Cohere、vLLM、OpenRouter、MiniMax、Bedrock 用户。
- **Desktop**：Windows WSL 和多服务器用户。

## 是否需要升级

大型项目、MCP、WSL 或新增模型用户建议升级；本版本也适合遇到上下文溢出和工作区移动问题的用户。

## 升级命令

```bash
opencode upgrade
```
