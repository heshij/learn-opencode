# OpenCode v1.18.7 更新日志

**发布日期**：2026-07-27

## 一句话总结

本版本修整 Desktop 在 macOS 全屏、命令面板和长项目列表下的界面行为。

## 新功能或行为变化

- 项目选择下拉列表在项目较多时支持滚动。

## 问题修复

- 移除 macOS 全屏模式标题栏多余的顶部间距。
- 修复被同名命令遮蔽的命令在移除后错误重新出现。

## 影响范围

主要影响 macOS Desktop 用户，以及使用大量项目或自定义命令的用户。

## 是否需要升级

遇到上述界面问题的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
