# v1.14.43：Provider API 与 ACP 附件修复

**发布日期**：2026 年 5 月 9 日

## 一句话总结

修复 Provider 配置 API 的序列化兼容性，并让 ACP 正确传递工具图片附件。

## 新功能或行为变化

- ACP 更新和会话重放现在包含工具产生的图片附件。

## 问题修复

- 修复认证加载器向 Provider 添加非 JSON 选项后，Provider 与配置 API 响应失效的问题。

## 影响范围

主要影响自定义 Provider、认证集成、HTTP API 与 ACP 客户端用户。

## 是否需要升级

使用相关 Provider API 或 ACP 图片附件时建议升级；其他用户可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
