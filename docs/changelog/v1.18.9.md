# OpenCode v1.18.9 更新日志

**发布日期**：2026-07-28

## 一句话总结

本版本恢复旧版 MCP SDK 客户端兼容性，并提高 Desktop v2 导航与首页加载稳定性。

## 新功能或行为变化

- 增加可选的 Desktop v2 sidecar，由随应用打包的 CLI 服务驱动。
- v2 设置中的模型 Provider 分组支持折叠。
- Desktop/Web 的 v2 迁移继续覆盖多服务器、标签页、新会话、终端和新客户端 API；MCP 的短期客户端兼容变更已回退，不属于公开 `@opencode-ai/sdk` 变更。

## 问题修复

- 恢复对旧版 MCP SDK 客户端的兼容。
- 修复 Solid 清理阶段崩溃导致 Desktop 导航中断。
- 修复首页会话列表更新时挂起整个页面，并移除 v2 首页项目视图多余的竖边框。

## 影响范围

影响 MCP 集成、Desktop/Web v2、首页会话列表和选择 sidecar 的用户。

## 是否需要升级

使用旧版 MCP 客户端或遇到 Desktop 导航问题的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
