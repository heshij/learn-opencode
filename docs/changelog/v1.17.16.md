# OpenCode v1.17.16 更新日志

**发布日期**：2026-07-09

## 一句话总结

本版本为 Grok 暴露推理强度选项，并增强 Desktop v2 的 Composer、文件浏览和审查工作流。

## 新功能或行为变化

- Grok 模型可选择推理强度，xAI Responses 模型的提示缓存路由和 PDF 支持得到改进。
- 首页项目新增“打开所在文件夹”，Composer 新增文件、命令、上下文和 Shell Mode 菜单，且不会丢失草稿。
- 侧边栏文件可在内联标签页中打开和预览；审查面板会记住每个会话的模式和文件。

## 问题修复

- 修复隐藏会话面板仍保持挂载造成的侧栏问题，以及大补丁初始 diff 截断后无法加载完整内容的问题。
- 修复命令面板首次打开闪烁、新会话快捷键路由和旧会话 URL 布局跳转。

## 影响范围

主要影响 Grok/xAI 用户，以及使用 Desktop v2 文件浏览、Composer 和审查面板的用户。

## 是否需要升级

使用 Grok 推理或 Desktop v2 审查功能的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
