# OpenCode v1.18.10 更新日志

**发布日期**：2026-07-30

## 一句话总结

本版本可自动发现 Modal 模型，并打磨 Desktop 的附件、标签页、通知和 Agent 选择体验。

## 新功能或行为变化

- 自动发现可用的 Modal 模型。
- 新会话按钮始终显示，Toast 通知改进堆叠、关闭操作和移动端布局。
- 优化标签页悬停、激活和溢出状态。

## 问题修复

- 防止重复添加同一个附件。
- 修复损坏的已保存标签页，避免错误状态跨启动保留。
- 模型数据加载完成前隐藏变体选择器，并为已有用户保留自定义 Agent 选择器。

## 影响范围

主要影响 Modal、Desktop、移动端 Web、附件和自定义 Agent 用户。

## 是否需要升级

使用 Modal 或遇到标签页、附件问题的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
