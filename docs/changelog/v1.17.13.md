# OpenCode v1.17.13：兼容模型推理与 V2 模型选择

**发布日期**：2026 年 7 月 1 日

## 一句话总结

OpenAI-compatible 推理模型会可靠应用推理设置，同时 v2 界面加入可搜索模型选择、问题提示收起和更清晰的多标签状态。

## 新功能或行为变化

- 对 OpenAI-compatible 推理模型强制启用 reasoning mode，使自定义部署可靠应用推理设置。
- 问题提示可最小化后恢复，不必直接关闭。
- Composer 新增可搜索的 v2 模型选择器和模型管理流程。
- 会话标签悬停预览会显示项目、路径、分支和服务器。
- WSL 服务器设置增加更清晰的发行版检查与安装流程。
- Desktop 标签按窗口隔离，每个窗口可恢复自己的标签集合。

## 问题修复

- 不再重放过期的 GitHub Copilot response item ID，避免后续请求失败。
- 清理过期的空草稿和旧草稿存储文件，减少 Desktop 状态堆积。
- 审阅待处理问题时保持请求打开，避免意外关闭。
- 会话页面错误仅影响当前标签，不再破坏整个应用。
- 改进 v2 会话中的 Markdown 和消息布局对齐。

## 影响范围

- **Provider / Core**：OpenAI-compatible 推理模型和 GitHub Copilot 用户。
- **Desktop / Web**：问题提示、v2 模型选择、多窗口标签和会话页面用户。
- **Desktop / Windows**：使用 WSL 服务器的用户。

## 是否需要升级

使用 OpenAI-compatible 推理模型、GitHub Copilot、WSL 或 v2 Desktop 多标签的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
