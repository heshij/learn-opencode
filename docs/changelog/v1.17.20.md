# OpenCode v1.17.20 更新日志

**发布日期**：2026-07-13

## 一句话总结

本版本移除可能干扰 Luna Responses Lite 的旧 Codex 兼容逻辑，并更新 Azure AI 的 GPT-5.6 支持。

## 新功能或行为变化

- 更新 Azure AI 对 GPT-5.6 的支持。

## 问题修复

- 移除过时的 Codex workaround，避免其干扰 OpenAI Luna Responses Lite 请求。

## 影响范围

主要影响 Luna Responses Lite、Azure AI 和 GPT-5.6 用户。

## 是否需要升级

使用上述服务或模型的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
