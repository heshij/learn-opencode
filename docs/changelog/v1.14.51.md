# v1.14.51：实验性后台子代理

**发布日期**：2026 年 5 月 15 日

## 一句话总结

加入实验性后台子代理，让任务可在你继续工作时运行，并修复多项 Provider、会话和附件问题。

## 新功能或行为变化

- 新增受实验开关控制的后台子代理，可让任务在后台继续执行。
- MCP 在应用内显示客户端注册和认证状态，并提供直接重新认证流程。
- NVIDIA 端点加入所需 billing origin header，LiteLLM 兼容基线更新为 `v1.85.0-rc.2+`。

## 问题修复

- 修复 worktree 创建遗漏 POST body、取消后会话卡在中断消息和压缩后重复自动压缩的问题。
- 修复 shell 截断输出流关闭、Azure `gpt-5.5` completions、Windows 应用检测和 DigitalOcean OAuth scope。
- 恢复超大图片附件自动缩放，并保留点击问题选项时的文本选择。
- HTTP API 不再暴露内部 named defect 详情。

## 影响范围

影响 Core、TUI、Server、SDK、MCP、Provider、Windows 和实验性子代理用户。

## 是否需要升级

想试用后台子代理或受上述会话、Provider 问题影响时建议升级；实验功能不应视为稳定接口。

## 升级命令

```bash
opencode upgrade
```
