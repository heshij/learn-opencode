# OpenCode v1.18.3 更新日志

**发布日期**：2026-07-16

## 一句话总结

本版本改进 Desktop 的子代理选择、首页会话搜索和 WSL 启动状态，并修复多项界面问题。

## 新功能或行为变化

- 子代理选择器停在第一项时，可按上方向键关闭。
- 首页命令面板现在可以搜索并打开会话。

## 问题修复

- 修复首页滚动时固定标题和会话列表行为异常。
- Desktop 报告启动就绪前会等待 WSL 服务器加载。
- 修复存在自定义 Agent 时选择器不可见；移除应用布局中无效的 Help 按钮。

## 影响范围

主要影响 Desktop、WSL、自定义 Agent 和首页会话搜索用户。

## 是否需要升级

使用上述功能或遇到首页滚动问题的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
