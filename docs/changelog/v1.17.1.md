# OpenCode v1.17.1：References 配置增强

**发布日期**：2026 年 6 月 10 日

## 一句话总结

本版本增强项目 references 的说明与可见性控制，并改进 MCP 超时、新会话草稿流程和 macOS 自动更新。

## 新功能或行为变化

- references 可为 Agent 提供使用说明、显示在新文档中，并可按需从 `@` 自动补全隐藏。
- 旧的单数 `reference` 配置仍可加载，但会归入新的 `references` 配置键；建议后续使用复数写法。
- Desktop 新会话使用独立的 `/new-session` 路由，草稿标签会在会话开始前保留提示词与项目选择。

## 问题修复

- MCP prompt 和 resource 请求现在遵守服务器超时配置。
- 修复 Anthropic fallback 响应处理。
- MCP 客户端初始化失败时会干净退出，不再留下损坏连接。
- 恢复 macOS 自动更新。

## 影响范围

- **Core / TUI**：使用 references 为 Agent 提供本地或 Git 仓库上下文的用户。
- **MCP**：配置请求超时或遇到初始化失败的用户。
- **Desktop**：使用新会话草稿和 macOS 自动更新的用户。

## 是否需要升级

使用 references、MCP 或 macOS Desktop 的用户建议升级；仍使用 `reference` 的配置可继续工作，但建议迁移到 `references`。

## 升级命令

```bash
opencode upgrade
```
