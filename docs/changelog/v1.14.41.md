# v1.14.41：恢复格式化与会话迁移能力

**发布日期**：2026 年 5 月 7 日

## 一句话总结

格式化器输出处理恢复正常，workspace warp、Desktop 本地服务和 ACP 会话恢复也更加可靠。

## 新功能或行为变化

- 会话 warp 到其他 workspace 时可以携带未提交的文件改动。
- macOS 新增 Settings 菜单项。
- Desktop 本地 Server 移到独立 utility process，以改善启动和关闭可靠性。
- ACP 加载会话时会恢复上次的模型、模式和 effort，并可正确关闭会话。

## 问题修复

- 恢复格式化器对 stdout 或 stderr 输出的处理。
- 恢复 `/connect` 中的自定义 Provider 设置。

## 影响范围

影响使用格式化器、workspace warp、自定义 Provider、Desktop 或 ACP 的用户。

## 是否需要升级

依赖格式化器或上述工作流时建议升级；否则可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
