# v1.14.40：远程配置与稳定性改进

**发布日期**：2026 年 5 月 7 日

## 一句话总结

企业配置可以指向独立远程 JSON，同时修复了网络、会话、模型和 Desktop 的多项稳定性问题。

## 新功能或行为变化

- `.well-known/opencode` 配置可通过 `remote_config` 指向独立远程配置文件；远程配置先加载，仍可被用户和项目配置覆盖。
- 会话 warp 只展示已连接的 workspace，并把新目录带入会话；`/new` 也会使用当前 workspace。
- `server_is_overloaded` API 错误会自动重试，压缩摘要会显示在保留的尾部消息之前。

## 问题修复

- 修复 signed reasoning 重放时助手文本丢失、缺失会话错误不一致，以及无效代理字符影响 Provider 转换的问题。
- 修复旧 Server 端点的 CORS、`serve`/`web`/ACP 网络参数、Web 终端 CSP 和 Cloudflare AI Gateway Provider 选项。
- 修复模型刷新后选择丢失、Mistral Medium 3.5 变体缺失、`/agent create` 路径错误和编辑器选区上下文变化。
- 修复 Desktop 剪贴板、日志 `EPIPE`、退出时自动安装更新、启动同步查询和生产环境噪声上报问题。

## 影响范围

主要影响企业远程配置用户，以及 Core、Server、ACP、Web、TUI 和 Desktop 用户。

## 是否需要升级

使用企业远程配置、浏览器客户端、workspace warp 或受上述问题影响时建议升级；其他用户可随常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
