# OpenCode v1.17.6：MCP 客户端能力声明

**发布日期**：2026 年 6 月 13 日

## 一句话总结

OpenCode 现在会向 MCP 服务器声明自身支持的客户端能力，从而提升协议协商兼容性。

## 新功能或行为变化

- MCP 客户端连接时会声明 OpenCode 支持的 capabilities，服务器可据此选择兼容行为。

## 问题修复

本版本 Release Notes 未单独列出问题修复。

## 影响范围

- **Core / MCP / Integrations**：连接会根据客户端 capabilities 调整行为的 MCP 服务器与用户。

## 是否需要升级

遇到 MCP 服务器兼容或能力协商问题的用户建议升级；未使用 MCP 的用户可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
