# v1.15.0：新的核心事件系统

**发布日期**：2026 年 5 月 15 日

## 一句话总结

核心事件系统迁移到 Effect，以提高会话和集成中的事件交付完整性。

## 新功能或行为变化

- 新增基于 Effect 的核心事件系统，改善会话与集成的事件交付。
- Linux 和 Windows 默认自动隐藏菜单栏。
- JavaScript SDK 恢复会话、消息等缺失事件类型。

## 问题修复

- 自定义工具模块中的无效 export 不再导致工具加载失败。
- 项目指令查找失败不再阻止会话加载。
- 修复版本化事件 projector 查找和未变化归档会话被重复处理的问题。

## 影响范围

影响 Core、会话事件、插件自定义工具、SDK、Desktop 以及各类事件驱动集成。

## 是否需要升级

依赖事件订阅、JavaScript SDK 或自定义工具时建议升级；其他用户可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
