# OpenCode v1.18.14 更新日志

**发布日期**：2026-08-05

## 一句话总结

本版本将 xAI 登录统一为更适合无头和远程环境的设备码流程，并提升 Provider 与远程工作区稳定性。

## 新功能或行为变化

- xAI 登录简化为单一设备码流程，更适合无头和远程环境。
- ACP 用量统计现在包含缓存写入。

## 问题修复

- 保留流式过程中的结构化 Provider 错误，并对更多临时 Provider 和网络错误执行重试。
- 远程工作区不再接收宿主机 `directory` 路径，提示会从远程项目根目录解析。
- 远程工作区 5xx 响应体会写入宿主日志，便于排查代理故障。
- ACP 会等待已排队的会话更新完成后再结束一轮。

## 影响范围

影响 xAI、ACP、远程工作区、代理环境和 Provider 集成用户。

## 是否需要升级

在无头环境登录 xAI、使用远程工作区或遇到临时网络失败的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
