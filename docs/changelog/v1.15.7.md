# v1.15.7：Grok OAuth 与 Desktop 新界面

**发布日期**：2026 年 5 月 21 日

## 一句话总结

新增 Grok OAuth 与 PDF 附件支持，强化 V2 API 错误安全性，并推出新的 Desktop 首页和会话入口。

## 新功能或行为变化

- 新增 Grok OAuth 登录，包括设备码流程，并支持向 Grok 发送 PDF 附件。
- V2 全局事件流新增账户添加、删除和切换事件。
- Desktop 新增首页、会话入口、标题栏、pinch zoom 设置和日志导出。
- V2 API 为未实现 mutation、缺失会话和未知错误返回明确类型与日志 reference ID。

## 问题修复

- 通用 API `500` 不再泄露配置细节，未知错误可通过 reference ID 对照 Server 日志。
- 合并并发 Codex OAuth 刷新，恢复原生 OpenAI OAuth 请求和 reasoning stream。
- 工具 schema 失败会显示友好错误；新会话默认使用本地项目。
- 修复单选问题 checkmark 布局和 callback URL 含多个冒号时 user code 提取。

## 影响范围

影响 Grok、OpenAI/Codex OAuth、V2 API、Server、SDK、Desktop 和 Web 用户。

## 是否需要升级

使用 Grok、OAuth、V2 API 或 Desktop 时建议升级，尤其适合需要更安全错误响应的部署。

## 升级命令

```bash
opencode upgrade
```
