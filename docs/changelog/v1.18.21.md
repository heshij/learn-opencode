# OpenCode v1.18.21 更新日志

**发布日期**：2026-08-21

## 一句话总结

本版本避免模型返回未知结束原因时过早停止，并修正 Vertex AI 多区域 Gemini 路由。

## 新功能或行为变化

- 模型报告未知结束原因时会继续响应，而不是提前停止。
- 两种 Desktop 布局都注册了归档会话命令。

## 问题修复

- Vertex AI 的 `eu` 和 `us` 多区域 Gemini 请求改用 REP 端点。
- 下一次文件搜索加载时保留现有结果，减少界面闪空。

## 影响范围

影响模型响应续写、Vertex AI Gemini、Desktop 会话归档和文件搜索用户。

## 是否需要升级

使用 Vertex AI 或遇到响应提前结束的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
