# v1.15.5：实验性 OpenAI runtime 与运行回放

**发布日期**：2026 年 5 月 18 日

## 一句话总结

预览原生 OpenAI runtime，并为交互式 `run` 增加历史回放，同时改善 TUI 和 Desktop 体验。

## 新功能或行为变化

- 可通过实验开关预览原生 OpenAI runtime。
- `run` 新增 `--replay` 与 `--replay-limit`，恢复交互运行时可展示近期历史。
- Desktop renderer 可发送系统通知，并新增免费额度和用量超限提示。
- PWA 状态栏颜色会跟随当前主题。

## 问题修复

- 修复插件工具使用 `ask` 时无法正确完成，以及 `/event` 订阅竞态导致更新遗漏的问题。
- 修复粘贴后提示布局不刷新、文件引用跨 workspace、复制时丢失粘贴内容和超长工具输出破坏布局的问题。
- 修复问题 dock 溢出、消息裁剪和纯空白输入仍显示 placeholder 的问题。
- Desktop 更新会安装最新可用版本，不再复用过期下载；大型会话时间线性能也得到改善。

## 影响范围

影响 OpenAI Provider、CLI `run`、TUI、Web/PWA 和 Desktop 用户。

## 是否需要升级

需要运行回放或受上述界面问题影响时建议升级；原生 OpenAI runtime 仍是实验功能。

## 升级命令

```bash
opencode upgrade
```
