# OpenCode v1.17.3：修复 Desktop 崩溃

**发布日期**：2026 年 6 月 10 日

## 一句话总结

这是一个紧急修复版本，解决 v1.17.2 Desktop 崩溃问题。

## 新功能或行为变化

本版本 Release Notes 未单独列出新功能或行为变化。

## 问题修复

- 修复 v1.17.2 Desktop 崩溃问题。

## 影响范围

- **Desktop**：已安装 v1.17.2 的桌面端用户。

## 是否需要升级

v1.17.2 Desktop 用户应立即升级；其他版本用户可直接升级到当前更新版本。

## 升级命令

```bash
opencode upgrade
```
