# OpenCode v1.17.11：会话快照与回滚

**发布日期**：2026 年 6 月 25 日

## 一句话总结

会话现在可以回滚到早先消息并恢复关联文件改动，桌面标签与异步操作的会话隔离也更可靠。

## 新功能或行为变化

- 新增会话 snapshot 与 revert 控制，可回到指定消息并回滚关联文件补丁；redo/unrevert 可恢复，`snapshot: false` 仅关闭文件恢复。
- MCP OAuth 始终打印授权 URL，浏览器无法自动打开时仍可手动登录。
- 新增 `mod+1` 到 `mod+9` 的 Chrome 风格标签切换快捷键和可拖拽标签。
- 改进无会话 Home 空状态、v2 跳到最新按钮、标题栏标签和归档会话布局。

## 问题修复

- 提示词草稿会保持在正确的项目服务器中。
- 修复标题栏标签尺寸、空列表时 Home 操作和会话切换时 todo dock 位置。
- 会话被删除后自动关闭对应标签。
- Provider 对话框、回滚和异步附件保持绑定到发起操作的会话。
- 打开会话后会清理迟到通知，并移除会话加载条纹。

## 影响范围

- **Core / TUI / Desktop / Web**：需要撤销会话消息和文件改动的用户。
- **Server / SDK**：调用会话 revert/unrevert 能力的集成开发者。
- **MCP**：需要手动完成 OAuth 登录的用户。

## 是否需要升级

需要会话回滚、文件恢复或多标签稳定性的用户建议升级；执行回滚前仍应确认目标消息和文件改动范围。

## 升级命令

```bash
opencode upgrade
```
