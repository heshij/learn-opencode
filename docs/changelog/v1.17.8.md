# OpenCode v1.17.8：会话时间线提速

**发布日期**：2026 年 6 月 17 日

## 一句话总结

会话时间线加载更快且减少闪烁跳动，同时集中修复 MCP schema、超时、OAuth 和 Cloudflare AI Gateway 配置问题。

## 新功能或行为变化

- 会话时间线显著加速，减少加载闪烁和滚动位置跳动。
- 新增 Home 标签切换，可在 Home 与上一个标签之间快速往返。
- v2 Desktop 的文件与目录选择器更快、更易导航。

## 问题修复

- 修复 OpenAI-compatible Provider 无法接受部分 MCP 工具 schema，以及无 properties 的工具 schema 兼容问题。
- 修复 Cloudflare AI Gateway 未收到已配置 API Key。
- MCP 长任务报告进度时会续期超时，服务器错误文本也会直接展示。
- MCP OAuth 回调服务器会在完成或取消后关闭，并对错误页面中的 Provider 文本进行转义。

## 影响范围

- **Desktop / Web**：长会话、Home 标签和文件选择器用户。
- **MCP / Provider**：OpenAI-compatible 模型、长任务和 OAuth MCP 用户。
- **Integrations**：Cloudflare AI Gateway 用户。

## 是否需要升级

长会话、MCP、Cloudflare AI Gateway 或 v2 Desktop 用户建议升级。

## 升级命令

```bash
opencode upgrade
```
