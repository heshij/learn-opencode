# v1.14.48：保留原始图片附件

**发布日期**：2026 年 5 月 11 日

## 一句话总结

图片附件发送给模型前不再缩放，而是保留原始内容。

## 新功能或行为变化

- 图片附件改为保留原始文件，不再在发送给模型前自动缩放。

## 问题修复

本版本 Release Notes 未单独列出问题修复。

## 影响范围

主要影响向模型发送图片附件的用户，尤其是需要保留原始分辨率和细节的场景。

## 是否需要升级

需要原始图片质量时建议升级；需同时留意更大的附件可能带来更高传输和模型处理成本。

## 升级命令

```bash
opencode upgrade
```
