# OpenCode v1.18.20 更新日志

**发布日期**：2026-08-21

## 一句话总结

本版本让失败的子代理任务返回可恢复的 `task_id`，并覆盖更多 Provider 网络错误重试场景。

## 新功能或行为变化

- 失败的子代理工具调用会显示可恢复的 `task_id`，不再返回空结果。
- `opencode run` 可回答子代理触发的权限请求。

## 问题修复

- Provider 返回 `finish_reason: network_error` 时重试，并覆盖 `network-error`、`network_error` 等更多网络错误形式。
- xAI 容量不足和临时不可用的流错误会重试。
- Cerebras 的 `max_completion_tokens` 会原样保留，不再额外叠加输出上限。
- 连同 v1.18.11 的 MCP SSE 修复，本版本进一步扩大网络失败的重试匹配范围。

## 影响范围

影响子代理、`opencode run`、Provider 网络重试、xAI 和 Cerebras 用户。

## 是否需要升级

使用子代理或经常遇到网络临时失败的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
