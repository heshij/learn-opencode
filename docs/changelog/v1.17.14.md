# OpenCode v1.17.14 更新日志

**发布日期**：2026-07-06

## 一句话总结

本版本加入实验性的 Code Mode MCP 编排能力，并集中改善 Desktop v2 的标签页、审查面板、终端和会话体验。

## 新功能或行为变化

- 启用 `OPENCODE_EXPERIMENTAL_CODE_MODE` 且存在获准的 MCP 工具时，会提供 `execute` 工具，在只能访问该 MCP 工具目录的受限环境中运行编排代码；未启用时隐藏该工具。
- 统一应用内 Provider 连接流程，改进集成终端、模型搜索和 v2 审查面板。
- Desktop 支持重新打开已关闭标签页、后台打开标签页，并在首页展示最近关闭的项目。

## 问题修复

- 修复分页 MCP 工具目录丢失元数据和输出 Schema 校验的问题。
- 修复 OpenRouter 小模型推理强度、GitHub Copilot 模型端点路由和 Cerebras 推理回放。
- 修复会话目录匹配、TUI 加载动画、Home 新会话项目选择、时间线补齐、标签页状态与子会话导航等问题。

## 影响范围

主要影响使用 MCP 的高级用户，以及 Desktop、Web、TUI、Provider 集成和多服务器会话用户。Code Mode 属于实验功能，默认不会出现。

## 是否需要升级

需要 MCP 编排、使用受影响 Provider，或正在使用 Desktop v2 的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
