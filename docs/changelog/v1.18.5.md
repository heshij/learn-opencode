# OpenCode v1.18.5 更新日志

**发布日期**：2026-07-24

## 一句话总结

本版本改善多家模型的推理与缓存兼容性，并让 Desktop v2 能识别和使用当前服务器与旧版服务器。

## 新功能或行为变化

- 改善 Claude 自适应思考对更多响应形态的处理，并保留 Mistral 跨轮推理历史、稳定提示缓存。
- Desktop 增加当前服务器的终端、审查数据、会话操作、时间线和事件流支持，并可识别新旧服务器。
- 共享 App 与 Desktop 的 v2 迁移继续扩展到多服务器、新客户端 API 和会话交互；旧服务器仍保留对应兼容路径。
- 文件专用标签页显示原始文件内容，不再显示审查 diff。

## 问题修复

- 避免 OpenAI Responses 阶段处理破坏对话，修复 MiniMax M3 思考变体和各 SDK 的提示缓存键。
- 搜索结果保留 grep 符号链接路径。
- 修复流式响应的乐观时间线、旧服务器文件提及、Agent 切换、分页时间线顺序和会话状态恢复。

## 影响范围

影响 Claude、OpenAI、Mistral、MiniMax 用户，以及连接新旧服务器的 Desktop 和 Web 用户。

## 是否需要升级

使用上述模型或多服务器 Desktop 的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
