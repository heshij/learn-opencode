# OpenCode v1.17.18 更新日志

**发布日期**：2026-07-09

## 一句话总结

本版本避免 GitHub Copilot 返回异常计费信息时崩溃，并改善 Meta Muse Spark 的模型适配。

## 新功能或行为变化

- 为 Meta Muse Spark 增加模型专用系统提示。

## 问题修复

- 修复 GitHub Copilot 返回计费批次大小为零的模型时导致崩溃或价格数据错误的问题。

## 影响范围

主要影响 GitHub Copilot 和 Meta Muse Spark 模型用户。

## 是否需要升级

使用上述模型的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
