# v1.15.1：安装恢复与会话界面改进

**发布日期**：2026 年 5 月 16 日

## 一句话总结

改善 npm 缺少原生二进制时的恢复流程，并加入可展开思考内容与固定会话快捷切换。

## 新功能或行为变化

- 新增默认折叠、可行内展开的 thinking 视图。
- 会话选择器支持固定会话和快速切换槽位，快速切换仅作用于固定会话。
- 自定义工具会保留 Zod schema 元数据和参数描述。

## 问题修复

- 改善 npm 安装，使 CLI 在更多环境中可获取正确的原生二进制，并补充恢复说明。
- 修复提示历史连续重复项、多行 `@` mention 和 `.git` 为符号链接时的文件监视。
- TUI 启动时展示完整配置校验错误，thinking 默认状态保持一致。
- 修复聊天输出中的 Markdown 表格渲染。

## 影响范围

影响 npm 安装、CLI、TUI、自定义工具、文件监视和 reasoning 输出用户。

## 是否需要升级

遇到 npm 原生二进制缺失、配置启动错误或 Markdown 表格问题时建议升级。

## 升级命令

```bash
opencode upgrade
```
