# OpenCode v1.18.22 更新日志

**发布日期**：2026-08-24

## 一句话总结

本版本移除过时的 OpenCode Go 优惠信息，并修复设备登录、OpenAI 兼容 Provider 和 Bedrock 适配。

## 新功能或行为变化

- 移除已经过期的 OpenCode Go 首月折扣文案和价格信息。
- 模型选择器滚动时保持 Provider 分组标题可见。

## 问题修复

- 修复服务器返回相对验证 URL 或带 base path 时的 OpenCode 设备登录链接。
- 不再向不支持 `textVerbosity` 的 OpenAI 兼容 Provider 发送该参数。
- 更新 Amazon Bedrock Provider 以修复兼容性问题。

## 影响范围

影响 OpenCode Go、设备码登录、OpenAI 兼容 Provider、Amazon Bedrock 和模型选择器用户。

## 是否需要升级

使用设备登录、OpenAI 兼容 Provider 或 Bedrock 的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
