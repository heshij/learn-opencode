# OpenCode v1.18.4 更新日志

**发布日期**：2026-07-20

## 一句话总结

本版本改善 Kimi 与 Azure 等 Provider 兼容性，并重写 Desktop v2 提示输入以提高交互可靠性。

## 新功能或行为变化

- Anthropic 兼容 Provider 上的 Kimi 模型使用自适应思考控制，默认输出推理摘要。
- v2 提示输入重写，改善命令、上下文、Shell、附件和历史记录交互。
- 终端主题跟随应用主题；审查面板增强文件标签对齐、缩放和固定控件。
- 命令菜单保留草稿，提示输入控件显示快捷键提示。

## 问题修复

- 修复 Provider 自定义推理选项被错误回退、Azure Cognitive Services 端点不可用和 OpenAI 连接阶段超时策略。
- 修复消息父链接缺失导致会话失败、空提示片段被发送、模型变体选择无障碍和重复 diff 文件项。
- 避免恢复窗口逻辑操作已经销毁的窗口。

## 影响范围

影响 Kimi、OpenAI、Azure 用户，以及 Desktop v2、终端、Composer 和审查面板用户。

## 是否需要升级

使用上述 Provider 或 Desktop v2 的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
