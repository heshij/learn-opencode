# OpenCode v1.18.19 更新日志

**发布日期**：2026-08-20

## 一句话总结

本版本为 Cloudflare AI Gateway 加入 OpenAI 和 Anthropic 原生透传，并改善多项 Provider 与账户连接行为。

## 新功能或行为变化

- Cloudflare AI Gateway 模型支持 OpenAI 和 Anthropic 原生透传。
- OpenCode Go Provider 启用 Web 搜索，并更新账户连接流程使用的默认 Console URL。
- ChatGPT 工作区的计算驻留设置会传给 Codex 请求。

## 问题修复

- Codex 速率限制更贴近 ChatGPT 订阅限制，移除可能不受支持的内置 Qwen 采样默认值。
- `/connect` 正确显示已认证 Provider，异常模型价格不再破坏用量成本计算。
- OpenAI WebSocket 请求超过消息大小限制时会回退。
- 保持 v1 数据库兼容，并允许在服务器对话框编辑已保存的服务器详情。

## 影响范围

影响 Cloudflare AI Gateway、OpenAI、Anthropic、Codex、Qwen、OpenCode Go 和 v1 数据库用户。

## 是否需要升级

使用上述 Provider 或连接流程的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
