# OpenCode v1.17.10：MCP Resources 与 Mini 模式

**发布日期**：2026 年 6 月 24 日

## 一句话总结

本版本把 MCP instructions、resources 和 templates 接入会话与工具系统，并新增 `--mini`、diff 主分支对比及 V2 Plugin API。

## 新功能或行为变化

- MCP 服务器 instructions 会加入会话上下文，并新增 resource template 列表与 resource 读取工具；权限拒绝时相关工具会隐藏。
- 新增 `opencode --mini` 精简交互模式。`opencode run` 默认仍是非交互命令，会话回放可用 `--no-replay` 关闭。
- diff viewer 新增可配置快捷键和与主分支比较功能。
- 新增移动端底部导航、可折叠服务器区块、服务器感知会话路由和安全区适配。
- SDK 暴露 Provider integration ID；Plugin 新增命名空间 hook API，以及面向 Effect 和 Promise 插件的 V2 API。
- Skill 基础目录改为文件系统路径，不再输出 `file://` URL。

## 问题修复

- 恢复旧版 MCP 工具名称与 v1 账户配置加载，并避免不同 MCP 服务器的 resource 工具键冲突。
- MCP OAuth 回调绑定 IPv4 loopback，提升本地认证可靠性。
- 修复子目录 snapshot 范围与路径、ACP 跨平台 resource 文本来源和文件源路径。
- 等待插件完成后再加载 reference 配置和系统上下文。
- 防止 worker rejection 终止 TUI，并修复草稿、会话导航、通知、Home 新会话和 review 行评论等问题。

## 影响范围

- **MCP / Core / Integrations**：使用 instructions、resources、templates、OAuth 和旧工具名的用户。
- **TUI / CLI**：需要精简交互、回放控制和 diff viewer 的用户。
- **Desktop / Web**：移动端、多服务器、草稿与会话导航用户。
- **SDK / Plugin**：开发 V2 Plugin 或 Provider 集成的开发者。

## 是否需要升级

使用 MCP resources、`--mini`、diff viewer、移动端界面或 Plugin API 的用户建议升级。

## 升级命令

```bash
opencode upgrade
```
