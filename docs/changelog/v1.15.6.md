# v1.15.6：TUI Diff Viewer 与 Shell Mode

**发布日期**：2026 年 5 月 20 日

## 一句话总结

TUI 新增文件树 diff viewer，`run` 增加 shell mode，并扩展 V2 API、Provider 与 Desktop 能力。

## 新功能或行为变化

- TUI 新增 diff viewer，可用文件树审阅改动，并自动聚焦第一个文件、折叠单子目录。
- `run` 提示区新增 shell mode，子代理标签改为按需选择器。
- Anthropic API Key 模型改用原生 runtime；V2 HTTP API 暴露结构化公共错误 schema。
- `opencode login` 默认连接 `https://console.opencode.ai`。
- Desktop 初步支持 tabs 和 Windows 原生菜单，并新增乌克兰语。

## 问题修复

- 单个插件文件加载失败不再中断其他插件；缺少 `args` 的插件工具也可继续加载。
- 修复相对配置路径中的 Agent/command 名称解析、无效 `OPENCODE_PERMISSION` JSON 启动崩溃和旧 `PgUp`/`PgDn` 别名。
- 修复 Zed 上下文误激活、导入会话目录字段、原生 runtime token 选择和自定义 Provider 更新后不立即显示。

## 影响范围

影响 TUI、CLI、插件、Provider、Server、SDK、Zed 和 Desktop 用户。

## 是否需要升级

需要 diff viewer、shell mode、V2 API 错误类型或 Desktop tabs 时建议升级。

## 升级命令

```bash
opencode upgrade
```
