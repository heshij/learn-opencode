# OpenCode v1.18.13 更新日志

**发布日期**：2026-08-04

## 一句话总结

本版本为 GitHub PR 审查补充链接上下文，并扩展 Desktop 的多语言与从右到左布局支持。

## 新功能或行为变化

- GitHub Pull Request 审查上下文现在包含 PR 编号和 URL。
- Desktop 和会话视图加入初步 RTL 布局支持、语言相关复数规则和更多语言。
- 扩大原生菜单、更新对话框、帮助内容等桌面文案的本地化覆盖。
- Markdown 解析移到主线程之外，以保持消息渲染时的界面响应。

## 问题修复

- 修复标签页、抽屉、缩放、标题栏、方向图标等多处 RTL 布局问题。
- 无标题会话会使用生成名称，不再显示为空白。

## 影响范围

影响 GitHub PR 审查用户、Desktop/Web 国际化用户，以及消息内容较多的会话。

## 是否需要升级

使用 GitHub 审查、RTL 语言或桌面多语言界面的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
