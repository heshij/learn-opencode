# OpenCode v1.18.0 更新日志

**发布日期**：2026-07-14

## 一句话总结

本版本完成 Desktop v2 布局迁移，同时保留过渡期的新旧布局切换选项，并改善会话与首页性能。

## 新功能或行为变化

- Desktop 完成 v2 布局迁移，包含升级处理和首次启动引导；过渡期可在设置中切换新旧布局。
- 共享 App 与 Desktop 的 v2 方向逐步覆盖多服务器、标签页、新会话、终端和新客户端 API；原生更新、WSL 和窗口生命周期仍是 Desktop 专属能力。
- 每台服务器分别保存权限自动接受状态，远程会话也可正确自动接受权限。
- 一次加载更多时间线历史，并显著缩短 Home 冷启动时间。

## 问题修复

- 修复 v2 文件背景、项目选择器定位及其崩溃、终端标签页抢焦点和重命名焦点问题。
- 修复重连后的时间线同步、底部锚定、Composer 光标保持和状态级别提示。

## 影响范围

主要影响 Desktop 和 Web 共享界面用户，尤其是多服务器、远程会话、终端及长会话用户。

## 是否需要升级

使用 Desktop v2 或受影响会话功能的用户建议升级；依赖旧布局的用户可先利用切换设置过渡。

## 升级命令

```bash
opencode upgrade
```
