# OpenCode v1.18.18 更新日志

**发布日期**：2026-08-13

## 一句话总结

本版本修复 Kimi 模型系统提示和 xAI 最高推理强度的适配。

## 新功能或行为变化

本版本 Release Notes 未单独列出新功能或行为变化。

## 问题修复

- 为 Moonshot 和 Kimi 官方 Provider 正确选择 Kimi 系统提示。
- 修复 xAI 模型的 `xhigh` 推理强度。

## 影响范围

主要影响 Moonshot、Kimi 和 xAI 模型用户。

## 是否需要升级

使用上述模型的用户建议升级；其他用户可按需升级。

## 升级命令

```bash
opencode upgrade
```
