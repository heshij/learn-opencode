# v1.14.46：内置配置 Skill 与安全修复

**发布日期**：2026 年 5 月 10 日

## 一句话总结

新增内置 `customize-opencode` Skill，并修复 HTTP API 类型、旧数据兼容和 Plan Mode 权限绕过。

## 新功能或行为变化

- 新增内置 `customize-opencode` Skill，降低编辑 OpenCode 配置导致启动失败的风险。
- HTTP API、OpenAPI 与 SDK 的数字和布尔查询参数保持一致。

## 问题修复

- 容忍会话、diff 和重试事件中的旧数字值，并修复负 token 数导致旧会话或 Desktop 启动失败的问题。
- 修复 MCP Server 发布损坏的 `outputSchema` 引用时工具发现失败的问题。
- 修复 workspace 路由查询参数在 HTTP API、OpenAPI 和 SDK 间漂移的问题。
- 修复 Plan Mode 下子代理可忽略父 Agent deny 规则的安全绕过。

## 影响范围

影响配置编辑、Server、SDK、MCP、旧会话、Desktop 和使用 Plan Mode 权限规则的用户。

## 是否需要升级

使用 Plan Mode、MCP 或 HTTP API 时建议尽快升级；其余用户也建议升级以提高旧数据兼容性。

## 升级命令

```bash
opencode upgrade
```
