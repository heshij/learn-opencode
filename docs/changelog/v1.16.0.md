# OpenCode v1.16.0：托管工作区与会话迁移

**发布日期**：2026 年 6 月 5 日

## 一句话总结

本版本重点增强工作区与会话迁移，并加入文件式 Agent、Skill 发现、Bedrock OpenAI 模型支持和更完整的 ACP 会话体验。

## 新功能或行为变化

- 新增托管工作区克隆，可保留未提交和未跟踪文件；会话也可在工作区或目录之间移动。该托管克隆是当时发布的历史实现，后续版本已转向 adapter/worktree 路径。
- 新增 Skill 发现和文件式 Agent 加载；Scout 在本版本中移除，项目上下文应改用 references。
- AWS Bedrock 正式支持 OpenAI 模型，并更新 GitHub Copilot 的 token 计费使用量追踪。
- 交互式运行支持 `run --replay`；ACP 恢复完整会话重放，并改进取消操作。
- 加入 Vue 语法高亮、颜色主题、v2 提示词思考级别选择、Settings 的 Servers 页与更新按钮。
- v2 响应新增会话位置数据；GitHub 集成在缺少 Git 作者身份时拒绝提交。

## 问题修复

- 修复 Shell 取消竞态、OpenAI WebSocket 会话空闲卡死，以及委派任务丢失推理 variant。
- 修复 SAP AI Core 的 OpenAI 推理 variant 与 Anthropic Opus 4.7+ 自适应推理。
- 修复 Windows 迁移存储路径、宽字符附近粘贴导致的提示词损坏，以及 ACP 取消未终止当前运行。
- 修复问题回复路由到错误目录、后台任务转圈不停止、会话审查刷新和 VCS diff 缓存等问题。
- 修复桌面标签标题、关闭按钮、更新入口和本地服务器启动错误展示。

## 影响范围

- **Core / TUI**：工作区、会话、Agent、Skill、提示词和交互式运行用户。
- **IDE / ACP**：加载、重放或取消 ACP 会话的编辑器集成。
- **Desktop / Web**：多标签、服务器设置、主题与会话位置相关界面。
- **Provider / Integrations**：Bedrock、SAP AI Core、GitHub Copilot 与 GitHub 集成用户。

## 是否需要升级

使用工作区迁移、ACP、Bedrock OpenAI 模型或遇到 Shell、WebSocket、粘贴问题的用户建议升级；其他用户可按常规节奏升级。

## 升级命令

```bash
opencode upgrade
```
